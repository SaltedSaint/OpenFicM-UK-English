# OpenFicM 0.10.3

## 修复：长内容弹层的“保存”按钮够不到，以及助手对话页频繁跳回顶部

本版修复 GitHub issue #2 与 #3，并一并修掉四处同类隐患。

### 世界书、角色编辑：内容变长后保存按钮消失（issue #2）

弹层只有 `maxHeight` 时，内部滚动容器默认不收缩（flexShrink 为 0）。条目内容超过弹层高度后会被顶出可视区，且容器自身的可滚动范围为零——“保存”按钮既看不到也点不到。

给滚动容器加 `flexShrink: 1` 后，长内容在弹层内正常滚动，按钮始终可达。笔记页与文风库此前已按同样方式修复，本版补齐世界书与角色两页。

### 助手对话页：多处滚动重置到顶部（issue #2、#3）

根因有两个：

- 助手页每次聚焦、以及任务完成后的数据刷新都会进入整屏 loading，把消息列表整体卸载重建，滚动位置归零。
- 进入对话页时没有定位到最新消息，发送消息后也没有主动滚到底部。

修复后的行为：

- 进入对话（含切换作品、切换会话）自动定位到最新消息。
- 智能体运行中与任务完成时，仅在用户已停留底部（距底 120px 内）时跟随滚动；翻阅历史时不会被打断。
- 切到其他标签页再回来，保留原来的滚动位置。
- 新增“回到最新消息”悬浮按钮：不在底部时出现在列表右下角，点一下回到底部。

### 一并修复的同类隐患

- 结构化提问弹层：问题较多时“提交回答”按钮会被顶出屏幕。
- 助手页的会话列表与模型选择列表：条目较多时无法滚动。
- 设置页的模型选择列表、供应商编辑与模型编辑弹层：内容超出弹层高度时无法滚动。
- 写作页的“作品目录”弹层：章节较多时无法滚动。

## 兼容性

- 沿用 0.7.0 起的正式签名证书，可直接覆盖升级。
- applicationId `com.openfic.mobile`，versionCode 21，minSdk 28，仅 arm64-v8a。
- 不涉及数据结构与迁移，升级不影响任何本地作品数据。
